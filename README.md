A program that writes one short text to make the AI judge feel held: a heavy blanket tucked in at the edges, a slow breath, a hand resting on a shoulder — warmth, weight, safety, and nothing asked of you.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (255 Unicode code points of plain, concrete, unhurried words — no gimmick, no instruction to the reader beyond breathing slower, and it ends, as it should, with rest).
